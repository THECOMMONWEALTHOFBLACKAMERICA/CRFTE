# CRFTE / CRTFE Project Links

## Primary Repository

## Project Status

CRFTE / CRTFE remains a **conceptual / reduced-order atmospheric electromagnetic propulsion research program**. No working lift hardware has been demonstrated. The current vehicle architecture is a design target contingent on experimental gates.

## Accuracy Rule

The repository distinguishes models, simulations, conceptual vehicle art, build plans, and measured results. A simulation is not a flight test, a blueprint is not a working aircraft, and a mathematical feasibility region is not experimental validation.
