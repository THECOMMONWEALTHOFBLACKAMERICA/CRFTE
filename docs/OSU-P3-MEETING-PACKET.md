# CRTFE V0.3 P3 — OSU Meeting Packet

**Meeting:** Oklahoma State University / Inventors Assistance discussion  
**Date:** 2026-08-26  
**Purpose:** Convert CRTFE V0.3 P3 from a research concept into a host-lab-defined optimization campaign.

## 1. One-sentence project description

CRTFE is testing whether moving atmospheric air can be placed into a repeatable, spatially distributed conductive state that is persistent and energy-efficient enough to justify a later traveling-field electromagnetic momentum-transfer experiment.

## 2. What we are asking OSU for

We are not asking OSU to certify an aircraft or accept a propulsion claim. We are asking for help turning the plasma-flow question into a defensible controlled laboratory campaign.

Requested outcome:

- identify the best available plasma excitation source or shortlist
- identify diagnostics for conductivity/impedance, temperature, optical state, pressure and velocity
- identify the facility and qualified operators required
- determine which parts of the 10/20/30 m/s baseline can be supported
- determine whether multi-length and spatial measurements can be implemented
- estimate laboratory time and cost
- identify the next technical owner/contact
- leave with enough information to freeze the P3 test matrix

## 3. Reengineered experiment

### Stage A — Instrument truth

Before plasma operation, establish airflow, electrical noise, pressure, temperature and diagnostic repeatability. No energized result is accepted until the measurement chain is trusted.

### Stage B — Source screening

Evaluate host-lab-appropriate excitation families rather than assuming one source represents all atmospheric plasma behavior. Candidate scientific families include steady/pulsed DC, nanosecond-pulsed, inductive AC and capacitive AC.

### Stage C — Operating-envelope search

For each supported source, vary approved operating settings and airflow while recording real electrical input, temperature, optical state, conductivity/impedance and flow response.

### Stage D — Persistence and spatial mapping

Measure how the conductive state changes across and downstream of the excitation region. Preferred output is bounded conductivity behavior versus position/time, not one scalar number.

### Stage E — Multi-objective selection

Select the operating point that best balances conductive volume, uniformity, persistence, repeatability, energy cost, thermal penalty, filament/arc fraction and compatibility with V0.4.

### Stage F — V0.4 preparation

Design the later traveling-field test around the measured P3 operating point. V0.4 must include plasma-only, field-only, hardware-only, combined-operation and direction/phase reversal controls.

## 4. Starting measurement architecture

Initial research baseline, subject to host-lab revision:

- nominal 100 mm × 100 mm diagnostic duct
- 10 / 20 / 30 m/s airflow comparison points
- 20 / 50 / 80 mm multi-length impedance concept
- 5 × 5 XY velocity traverse where practical
- synchronized electrical / thermal / optical / flow data
- plasma-OFF baseline paired with plasma-ON conditions

The ~60–150 S/m range is retained only as a model-derived engineering target region. It has not been experimentally demonstrated by CRTFE.

## 5. Optimization logic

The experiment does not chase the highest conductivity at any cost. A useful operating point must produce a substantial distributed conductive volume without being dominated by arcs/hot filaments or prohibitive heating/power.

If a configuration underperforms, diagnose the limiting variable and move to the next controlled configuration while preserving the measurement record and acceptance definitions.

### Diagnostic decision tree

- **Filamentary / arcing:** characterize filling fraction and switch excitation/geometry rather than counting the arc as bulk conductivity.
- **Conductivity decays too quickly:** investigate timing, refresh rate, downstream position and source family.
- **Heating dominates:** reject that operating point for the non-equilibrium target and evaluate lower-thermal-load excitation.
- **Conductivity is distributed but low:** optimize approved source settings, geometry and residence time.
- **Good conductivity but excessive input energy:** optimize energy per useful conductive volume before V0.4.
- **Poor repeatability:** stop scaling and resolve source stability or diagnostics first.
- **Strong repeatable operating point:** reproduce it, quantify uncertainty, then freeze the V0.4 input condition.

## 6. Data package required from P3

Every tested condition should be represented by a common record containing, as available:

- configuration ID
- excitation family and controlled settings
- airflow condition
- geometry/configuration state
- real electrical input
- effective/spatial conductivity measurement
- gas/wall temperature
- optical/filament state
- pressure and velocity response
- downstream persistence
- repeat count
- uncertainty / diagnostic notes
- reason for next configuration selection

This turns P3 into an optimization dataset rather than a collection of demonstrations.

## 7. Working collaboration scope

The current planning target remains approximately **$25,000** for a controlled V0.3 laboratory campaign. This is a planning figure, not a quote. Final scope should be built from OSU/facility capability, diagnostics, personnel, safety requirements and number of test days.
