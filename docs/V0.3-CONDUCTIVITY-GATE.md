# V0.3 Conductivity Gate

## Purpose

V0.3 is the next decisive experiment. Its purpose is **not** to generate thrust. Its purpose is to determine whether moving atmospheric air can reach the conductive state required by the V5 traveling-field model without unacceptable heating, filamentation, or auxiliary power.

## Required measurements

Measure the following under controlled moving-air conditions:

- `σ_eff(t)` — effective bulk conductivity over time
- `P_ionization` — real electrical input to create/refresh conductivity
- `T_g` / bulk `ΔT` — gas heating
- conductivity decay lifetime
- airflow velocity
- spatial uniformity / filamentation
- downstream momentum footprint if discrete channels appear

## Diagnostic logic

### 1. Bulk complex impedance

Use multi-length measurements so that true volumetric resistance can be separated from electrode/sheath/interface effects.

For a bulk conductor:

```text
R_p = L / (σ A)
```

If electrode spacing changes from `L1` to `L2`, the bulk-resistance term should scale approximately linearly with distance.

### 2. Temperature

Track gas temperature separately from electron excitation. A highly conductive state that only exists as a hot arc is not success for the current non-thermal architecture.

### 3. Spatial uniformity

A bright discharge is not sufficient. Determine whether conductivity is:

- volumetric/diffuse,
- streamer-dominated,
- filamentary,
- or thermal/arc-like.

### 4. Lifetime

Measure decay after each ionization event. The propulsion model needs not only average conductivity but also minimum instantaneous conductivity and refresh cost.

## Why failures must be classified

A result of 15 S/m can mean very different things:

- **filamentation:** local conductivity is high but spatial filling is poor;
- **rapid recombination/attachment:** useful conductivity exists briefly but decays too fast;
- **thermal quenching / arc transition:** conductivity costs too much thermal energy;
- **uniform but low σ:** discharge geometry is good but field/ionization strength is insufficient.

The remedy — or decision to stop — depends on which failure mode is observed.

## Decision protocol

| Measured behavior | Action |
|---|---|
| Bulk σ < 20 S/m | Stop / major architecture pivot for current full-channel design |
| Bulk σ 20–60 S/m | Borderline; only redesign / high-field studies justified |
| Bulk σ ≥ 60 S/m | Re-run V5 with measured P_aux, thermal data, lifetime, and ripple |
| Bulk σ 80–150+ S/m | Preferred region if power and heating still fit |
| Filamentary/streamer conduction | Route measured parameters into V4 failure model |
| Thermal arc only | Treat as a different hot-plasma architecture with full thermal penalty |

## P_aux update rule

Once the experiment exists, replace placeholder auxiliary allowances immediately:

```text
P_aux = measured ionization power
      + measured drive losses
      + measured electronics losses
      + measured cryogenic/support losses
```

Do not preserve a favorable 5 or 8 kW assumption if measured values are higher.

## What happens after a pass

If V0.3 produces a volumetric conductive state in the useful range at acceptable power/heating, then proceed to a small **phase-reversible MHD force test**.

That experiment should verify that changing field direction or traveling-wave phase order reverses the measured force in the manner predicted by `J × B`.

## Current program rule

> Stop broad vehicle-scale optimization until V0.3 returns measured `σ_eff(t)`, `P_aux`, temperature, lifetime, and uniformity data.
